# 我是水果王（IAmFruitKing）v1.0.0

一款基于 **Phaser 3** 的回合制弹射对战小游戏：双方轮流出招，用水果炸弹把对手炸进水里，最后站在场上的就是「水果王」。

- 在线预览：https://js-jc.github.io/fruit-king-battle/
- 技术栈：Phaser 3.80.1 + 原生 JavaScript，纯静态、零依赖构建，打开即玩
- 作者：Jason

## 玩法简介

- 回合制：我方 → 敌方交替行动，每回合可做一件事（投掷 / 放置 / 移动）。
- 投掷：拖拽蓄力瞄准，抛物线预测线辅助，命中造成伤害并击退。
- 道具：
  - 樱桃炸弹 —— 轻巧炸弹，落地爆炸
  - 西瓜炸弹 —— 威力大，击退强
  - 香蕉弹 —— 落地弹跳，可手动引爆
  - 水果箱 —— 放置障碍，冷却 1 回合
- 单位：水果王、苹果卫兵、柠檬将军、葡萄士兵，各有属性差异。
- 胜负：血量归零或落水即淘汰，全歼对方获胜。
- 暂停界面：继续 / 音效 / 音乐 / 返回标题。

## 目录结构

```
index.html          游戏入口（本地 Phaser 优先，CDN 兜底）
游戏说明.md          面向玩家的详细说明
lib/                Phaser 3 引擎（本地内置，断网可玩）
data/               单位 / 道具 / 地图 / 回合配置（json + 运行时镜像 .data.js）
js/
  config/           常量、事件、回合状态机、配置加载器
  data/             配置数据结构
  systems/          战斗系统（投掷、移动、伤害、AI、回合流转等）
  entities/         单位与道具实体（含香蕉弹）
  registry/         注册表
  ui/               道具栏、HUD、瞄准指示、暂停面板、结算面板
  scenes/           Boot / Battle / Result 场景
assets/             音效等资源
```

## 本地运行

直接双击 `index.html` 即可运行；也可用任意静态服务器托管（如 `python -m http.server`）。
